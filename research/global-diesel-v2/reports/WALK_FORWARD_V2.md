# WALK_FORWARD_V2

## 测试前冻结的实验协议

1. 日期、端点、availableAt、标签定义见Target报告；阈值1.5%只用2013—2016确定。
2. 验证2018：2013—2016训练、2017校准、2018验证。验证2019：2013—2017训练、2018校准、2019验证。逐块purge尚未公布标签及跨边界端点。
3. 两个验证年合并，按Brier最小选择**校准后的**候选；只在六位小数相同情形优先分布路线、然后log loss。未经校准raw只能比较，不能上线。
4. 验证冻结候选：**vol_historical_platt**，Brier 0.650064、log loss 1.073405；历史频率0.669107 / 1.102058。这是验证集选择结果，不是正式效果结论。
5. 正式测试2020—2026：每一年以前一年校准、更早所有年份训练，分别生成当年预测。2026为不完整年度，不算完整年度稳定性分母。2018/19属于过去，可以进入后续训练。每年只训练一次，测试期间不自适应。
6. 同时保留所有5路线×3校准方式作为诊断，但**正式Gate只看预先选定候选**，不得改选测试赢家。

## 模型固定规格

- Logistic：StandardScaler仅训练fit；C=.05，max_iter=2000。
- Hist classifier：100迭代、7叶、min_leaf=40、L2=5、learning_rate=.05；关闭随机early stopping。
- Regression + residual：Ridge alpha=100。训练前75%（清除跨内部分界标签）预测后25%残差；残差为按时间留出的误差，再用完整训练拟合均值。经验残差CDF转三类概率。
- Quantile：7个Hist回归器预测.05/.10/.25/.50/.75/.90/.95分位。单行分位排序消除交叉；两端各延伸一个5%—95%宽度构成0/1尾端，分段线性CDF积分至±1.5%。这是轻量近似，尾部假设有局限。
- Volatility-conditioned historical simulation：训练集中按20观察波动率的log距离选最近250个历史样本，将它们的未来7日收益先除以各自当时已知波动率×sqrt(5)，再按查询当时波动率重标。历史标签在训练截止前可知，无额外Monte Carlo随机抽样误差。
- Platt-style：校准年log-probability输入的多分类logistic（C=1）。Isotonic逐类拟合后归一化；归一化会影响单类校准，所以必须报告实测结果。校准器只看前一年。
- Baselines：训练历史频率（Laplace+1）；零变化；最近已公布柴油7日动量；反向动量。后三者为固定方向分布，90%放方向、10%训练频率平滑，避免零概率无穷log loss。不是手写产品概率。
- 种子20260928，线程固定1。未优化超参数或筛选测试特征。

## 重叠与Gate（在正式测试前定下）

- 严格 `labelKnownAt < 下一块起始决策时刻`，并断言上块末端点早于下块首起点；详见`fold-audit.json`。
- 贪心非重叠检查：下一个T严格晚于前一个终点，跨年连续选择。额外28日时间块bootstrap 2,000次给改善95%区间，保留邻近快照依赖；不能当每日独立样本CI。
- Brier、log loss都比最强简单基线至少改善2%；相对历史频率bootstrap下界>0；非重叠样本两项也必须改善。
- 平均classwise ECE优于频率，且每类ECE≤.05（10个固定等宽概率桶）。
- 至少2/3完整年份两项proper score改善且ECE不比频率差超过.02；至少2/3完整年份proper score退化不超过5%。
- 每类recall≥.10、预测占比≥3%；55%—65%概率桶各类须至少30个非重叠样本且实际频率与平均预测相差≤10个百分点。样本不足判未证明，不能当作校准通过。
- 历史≥5年、合法无付费、时间无泄漏、冻结身份一致、当前观察/发布≤7日龄。存在合法MGO历史才进行外域门槛；本轮无历史则记录NOT_EVALUATED，不能把它当代表性PASS。

正式结果、分年表、非重叠结果和区间由重跑脚本输出到其余报告。Gate失败即停止生成当前预测及模型制品。
